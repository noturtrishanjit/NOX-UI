NOX UI

NOX UI is an advanced voice-controlled Android launcher designed especially for disabled users and people with accessibility needs. The launcher allows users to control their smartphone completely through voice commands, reducing the need for physical interaction with the device.

Features

- Full voice-controlled navigation
- Open apps using voice commands
- Make calls and send messages hands-free
- Smart AI assistant integration
- Simple and clean accessible interface
- Fast, lightweight, and optimized performance
- Accessibility-focused design for visually or physically challenged users

Purpose

NOX UI aims to make smartphones more accessible, independent, and easier to use for everyone. The project focuses on improving digital accessibility through AI-powered voice interaction.

Technologies Used

- KOTLIN
- JAVA
- AI Voice Recognition APIs

Future Goals

- Offline voice assistant support
- Multi-language voice commands
- Gesture and eye-tracking support
- Smart emergency assistance system

Developer

Created with the vision of building technology that helps people live more independently and comfortably.
